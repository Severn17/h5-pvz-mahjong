# 执行计划：塔防 × 麻将 × 跑酷（肉鸽版）

> 工作副本：`h5-pvz-mahjong/`（拷贝自 `h5-game-plantsVSzombies/`，含其本地未提交的"肉鸽版"改动与 `.git` 历史）。
> 原仓库保持不动，作为对照基线。

---

## 0. 一句话定义

**用麻将凑牌代替阳光来种植物的肉鸽塔防**：摸牌 → 凑顺子/刻子种植物 → 听牌时赌"胡牌大招" → 关卡之间用小羊跑酷抢牌。单局 4–6 分钟，浏览器/小游戏直接玩。

## 1. 设计支柱（所有取舍按这个顺序判断）

1. **"听牌"的两难**：拆牌救急 vs. 憋大招——这是整个游戏最核心的乐趣，任何设计都不能削弱它。
2. **零学习成本**：会打麻将就会玩；不会麻将的人只需要懂"三张连号/三张相同"。
3. **张弛节奏**：塔防（紧张思考）→ 跑酷（放松爽快）→ 三选一（构筑期待），循环往复。
4. **短局可重玩**：每局随机牌山 + 随机强化 + 随机关卡特性。

---

## 2. 核心玩法设计

### 2.1 局内循环

```
开局祝福(三选一) → 第1关塔防 → 小羊跑酷(抢牌) → 强化三选一 → 第2关 → … → 第4关 Boss
```

### 2.2 牌与牌山

| 项 | MVP 规则 |
|---|---|
| 牌组 | 条 / 饼 / 万 各 1–9 × 4 张 = 108 张；字牌只放 **中、发、白** 各 4 张 = 12 张；共 120 张 |
| 牌山 | 每关开始洗一副新牌（种子化随机，便于复现），HUD 显示**剩余张数**，可点开看各牌剩余数（记牌也是策略） |
| 手牌上限 | 8 张（强化可 +1） |
| 摸牌 | 每 4 秒自动摸 1 张；手牌满时暂停摸牌并闪烁提示"请出牌" |
| 天降牌 | 复用原"天降阳光"：每 10 秒掉落 1 张明牌，点击拾取（手牌满则无法拾取） |
| 弃牌 | 拖出手牌区或选中后点"打出"；弃牌进弃牌河（可见） |

### 2.3 凑牌 → 种植物（取代阳光与卡片冷却）

选中手牌里的 3 张 → 若构成面子，生成一张**待种植物**（最多暂存 3 个）→ 点草坪格子种下。

| 花色 | 定位 | 顺子（123…789） | 刻子（三张相同） |
|---|---|---|---|
| **条** | 攻击 | 1-3 起头：豌豆射手；4-6 起头：寒冰射手 / 双发射手（按中间数字奇偶）；7 起头：机枪射手 | 三线射手（+30% 伤害） |
| **饼** | 防御 | 1-3：坚果墙；4-6：地刺；7：土豆地雷 | 强化坚果墙（生命 ×2） |
| **万** | 功能 | 1-3：向日葵（改为**加速摸牌 15%**，可叠加）；4-6：大嘴花；7：窝瓜 | 招财花：立即摸 2 张 |
| **字牌** | 爆发 | —（字牌不能成顺子） | 中：樱桃炸弹；发：火爆辣椒；白：全屏减速 5 秒 |

- **对子**：字牌对子 = 单次小爆发（原效果 50%），数字对子不能单独使用（保留给胡牌做雀头）。
- **杠**（4 张相同）：选中一棵已种植物，升一星（伤害/生命 +50%，最多 3 星）。
- 同时保留**铲子**：铲掉植物返还 1 张该花色随机牌。

> 数值是初版，全部写在 `js/data.js` 的表里，可随时调。

### 2.4 胡牌大招（核心爽点）

- **胡牌条件**（为快节奏缩短）：手牌 8 张 = **2 面子 + 1 雀头**；或 **4 对子**（七对子简化版）。
- 满足时"胡！"按钮亮起并有**听牌提示**：差一张时手牌发光、显示"听：3条 / 6条"及其牌山剩余数。
- 点击胡牌：全屏特效 + 对所有僵尸造成 `300 × 番数` 伤害，然后清空手牌、立即摸 5 张。

| 番型 | 条件 | 倍数 |
|---|---|---|
| 平胡 | 基础 | ×1 |
| 断幺 | 没有 1、9、字牌 | ×1.5 |
| 碰碰胡 | 面子全是刻子 | ×2 |
| 七对 | 4 对子 | ×2 |
| 混一色 | 一种花色 + 字牌 | ×2 |
| 清一色 | 只有一种花色 | ×4 |
| 字一色 | 全是字牌 | ×8（传说） |
| 自摸 | 摸到的最后一张牌让你胡牌 | 额外 +0.5 |

番数可以叠乘，上限 ×16。每关首次胡牌额外掉一个强化小奖励。

### 2.5 麻将味的僵尸（M3 引入）

- **碰碰僵尸**：会捡弃牌河里的牌，捡满 3 张就"碰"，变成狂暴状态；击杀后牌退回牌山。→ 让弃牌也要动脑子。
- **摸牌僵尸**：啃植物时偷走你手里的 1 张随机牌。
- **Boss 庄家僵尸王**：半血时"洗牌"，把你的手牌全部换掉。

### 2.6 小羊跑酷（关卡之间，约 25 秒）

- 3 条跑道自动前进，速度逐渐加快；←/→（触屏左右滑）换道，↑/上滑跳跃。
- 跑道上的东西：**麻将牌**（捡到进入"开局手牌"，最多 5 张）、**金牌**（强化三选一多刷新 1 次）、僵尸和路障（撞到会掉 1 张已捡的牌并短暂无敌）。
- 结算后进入强化三选一；捡到的牌成为下一关的起手牌，**跑酷表现直接影响塔防开局**。
- Boss 关前改为**追逐版**：僵尸王在身后追，只要撑到终点就给 Boss 关一个额外开局增益。

### 2.7 强化池改造（基于现有 `UPGRADES`）

- **删除/改写**阳光类强化：阳光储备 → **"满手好牌"**（立即摸 3 张）；精打细算 → **"万能牌"**（获得 1 张赖子，可以当任意牌用）；复利 → **"宝牌"**（每关随机指定一种牌，含宝牌的面子植物 +50%）。
- **新增**麻将类：手牌上限 +1；摸牌速度 +20%；换牌（每关 3 次，打 1 摸 1 不计时）；**听牌时所有植物攻速 +30%**（直接奖励听牌状态）；番数 +1 档；自摸奖励翻倍。
- 射手/防御/爆炸类强化**基本保留**，只需要把"冷却/阳光"相关的描述改掉。

## 3. 现有代码 → 改造映射

现有结构（原生 JS，无构建，`index.html` 按顺序加载脚本）：

| 文件 | 现在的职责 | 改造 |
|---|---|---|

| **`js/mahjong.js`（新增）** | — | 纯逻辑，不碰 DOM/canvas：`Deck`（种子洗牌、摸牌、剩余数）、`classifyMeld(tiles)`、`isHu(hand)`（回溯拆牌）、`waits(hand)`（听哪几张）、`calcFan(hand, ctx)` |
| `js/game.js` | 主循环、关卡流程、阳光、卡片栏、输入、绘制 | 把 `sun/cards/cost/cardCd/cardReady/selectCard` 换成 `deck/hand/pendingSeeds`；`update` 里加摸牌计时；`onClick` 加手牌区命中；`drawCards` → `drawHand`；`stageCleared` 后先进入 `'runner'` 状态再进 draft；新增 `declareHu()` |
| `js/entities.js` | `Plant/Zombie/Pea/Sun/Mower/Effect/Particle` | `Sun` 改为 `TileDrop`（天降牌）；向日葵产出从阳光改为 `game.drawBoost`；`Plant` 加 `star` 等级；新增碰碰僵尸行为 |
| `js/ui.js` | HUD、三选一、暂停、结算 DOM | HUD：阳光框 → 牌山剩余数 + 胡按钮 + 听牌提示；结算页加"最大番型"统计 |

| `index.html` | 页面骨架与脚本顺序 | 加 `mahjong.js`、`runner.js`；改标题与规则文案 |

**状态机**（在 `Game.state` 上扩展）：`loading → title → draft → playing ⇄ paused → runner → draft → playing … → victory / over`

- [ ] 单元测试：用 `node --test` 跑 `tests/mahjong.test.js`，覆盖顺子/刻子/杠识别、胡牌拆解（含多种拆法）、听牌计算、各番型（0.5 天）
- [ ] 程序化绘制牌面，替换顶部卡片栏为手牌栏（8 格）+ 待种植物槽（3 格）（1 天）

## 6. 测试策略

- **纯逻辑单测**（`node --test`）：`mahjong.js` 必须 100% 覆盖胡牌/听牌/番型——这是最容易出错、也最影响体验的部分。`mahjong.js` 末尾加 `if (typeof module !== 'undefined') module.exports = {...}`，让浏览器和 Node 共用一份代码。
- **种子复现**：牌山和跑酷生成都用种子随机，`?seed=123` URL 参数可以固定一局，方便复现 bug 和调平衡。
- **手动冒烟清单**（每个里程碑结束时过一遍）：完整打通 4 关；手牌满时的行为；暂停/切后台；加速 2× 下胡牌；触屏操作。

## 7. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 麻将 + 实时塔防认知负担太重 | 核心玩法不成立 | M1 设为 Go/No-Go 关卡；可退回"半实时"：摸牌时游戏减速 |
| 胡牌太难或太容易 | 大招没有期待感或者太泛滥 | 胡牌条件和手牌上限都是参数，靠试玩数据调 |
| 跑酷打断塔防节奏 | 流失 | 控制在 30 秒内，可以设置"跳过"（跳过则不给牌） |
| 素材版权（原版 PvZ 素材 + 第三方拆包） | 无法商用/下架 | M5 全部替换，发布前做素材清单审查 |
| 原生 JS 代码继续膨胀 | 后期难维护 | 新增逻辑全部放进独立文件（`mahjong.js` / `runner.js`），`game.js` 只做调度 |

## 8. 成功指标（外部试玩阶段）

- 单局完成率 ≥ 60%，平均单局 4–6 分钟
- 每局平均胡牌 ≥ 2 次，其中高番（≥ ×2）占 20% 以上
- 次日回访 / 再来一局率 ≥ 40%
- 胡牌截图分享（后续加"分享本局最大番"按钮）
